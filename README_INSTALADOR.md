## ⚡ PASSO RÁPIDO (5 minutos)

### 1️⃣ Instalar NSIS uma única vez
```
https://nsis.sourceforge.io/
```
- Baixe e instale
- **IMPORTANTE**: Marque "Add to PATH"
- Reinicie Windows

### 2️⃣ Gerar o `.exe`
Clique 2x em: **`GERAR_INSTALADOR.bat`**

Pronto! Um arquivo `Sublimix-Instalador.exe` será criado ✨

---

## 📦 Distribuir Instalador

Seu arquivo `Sublimix-Instalador.exe`:
